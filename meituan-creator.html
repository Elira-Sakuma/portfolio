01 / BACKGROUND

项目背景与核心痛点

美团点评的内容生态依赖创作者持续产出优质内容来驱动用户消费决策。策略中台团队当时面临四个核心痛点。

[01]
分层不清晰
创作者分层不清晰，运营资源"一刀切"——头部觉得没价值、尾部觉得没机会。
[02]
引进缺标准
站外达人引进缺乏标准化流程，依赖人工经验判断，效率低且不可复制。
[03]
运营重复高
手动筛选达人、手动配置权益、手动追踪数据，运营动作重复性高，策略设计时间被挤压。
[04]
复盘无数据
缺乏数据驱动的复盘机制，策略迭代靠感觉不靠数据，无法归因效果。
02 / TIER SYSTEM

三层激励体系

对创作者进行月度分层定义，核心维度为过往笔记累计曝光、活跃度、粉丝数。每个层级对准创作者不同阶段的核心诉求，设计差异化激励机制。

3.1 月度分层定义与差异化激励
Tier Definition Core Need Incentive
头部 · 成熟期 累计曝光前30% + 7天内有活跃 影响力扩大、多元变现 站内"点小评"等官方号翻牌曝光；争取平台线下活动名额（如点评必住榜酒店试睡官、平台大型活动约稿）
腰部 · 成长期 曝光30%-50% + 30天内有活跃 稳定流量、突破瓶颈 "可能认识的人"推粉位（好友弹窗快速增长粉丝）；每日流量包1000；细分垂类爆款榜单展示
尾部 · 新作者 新入驻创作者 低门槛参与感、冷启动 7天内发布3篇笔记即触发冷启动奖励（美团卡）；提供创作内容参考playbook、近期站内站外热点清单
3.2 新作者冷启动任务具体要求
新作者的冷启动是整个体系最关键的环节——降低首次发布门槛，让新创作者快速体验到"被看见"的正反馈。
  • 内容方向：平台主要推广的探店、美食、旅游、城玩
  • 内容结构：包含时间、地点、感受、特色等
  • 质量标准：带有强去处关联，不少于6张照片或30s视频，200字以上正文
  • 配套支持：创作内容参考playbook + 近期站内站外热点清单
03 / CREATOR PIPELINE

站外达人引进全流程

制定标准化筛选标准、分层扶持权益、招募渠道，将达人引进从"依赖人工经验"变成"可复制的流程"。

STEP 01
筛选标准
拆解创作者核心要素，在数据平台定向筛选优质达人。
  • 粉丝数 · 创作类型
  • 更新频率 · 画风
  • 商业合作信誉
STEP 02
垂类适配
优先定向挖掘匹配平台内容生态需求的创作者。
  • 旅行创作者
  • 美食创作者
  • 城市玩乐创作者
STEP 03
分层扶持
按站外粉丝量分层，提供差异化流量资源。
  • 10万+ → 每日投流、专属运营帮选题
  • 统一开放扶持入口
STEP 04
配套服务
全链路服务保障达人入驻后的持续运营。
  • 原创版权保护
  • 优先提报曝光
  • 官方榜单展示
  • 1对1专属运营
▼ OUTPUT · 达人入驻全链路闭环
从"依赖人工经验" → 标准化可复制流程 · 活跃达人 +15% · 优质内容供给 +20%
04 / CAMPAIGN

"回小城过个好玩年"活动

作为核心策划者，从创意发想到达人落地的全链路推动。

06 / TAKEAWAY

我的收获

[01]
创作者分层的本质是"对准诉求"
不是简单按粉丝数分，而是按创作者所处阶段的核心诉求分——头部要影响力、腰部要流量、新作者要参与感。激励设计必须对准诉求，否则资源投入再多也无效。
[02]
数据驱动是运营的思维方式
SQL不只是取数工具，更是一种思维方式——从数据异动定位根因，用数据验证策略效果，让迭代有依据而非靠感觉。
[03]
工具化思维让运营变成策略设计
运营工作中大量动作是重复的（筛选、配置、追踪），把这些动作工具化不仅提升效率，更重要的是让运营从执行者变成策略设计者。
[04]
好的活动是找到"真实表达欲"
好的内容活动不是让达人"完成任务"，而是找到他们本来就愿意记录的情绪和场景。"回小城过小年"之所以有效，是因为返乡情感是真实的表达欲。
